The Captide API unlocks **structured access to a rich corporate disclosure database**, powered by agentic AI systems. Designed for hedge funds, investment banks, and developers, it enables the creation of RAG-based applications with built-in source attribution.

Base URL: `https://rest-api.captide.co`

## API Structure

<AccordionGroup>
  <Accordion title="Companies" icon="building-columns">
    Endpoints to access Captide’s company database and perform metadata-based screening.

    `GET /api/v2/companies/list`\
    Retrieves the companies that match your filters: tickers, countries of domicile, SEC filing status, CIKs, PermIDs or Captide company IDs. The response includes each company’s name, ticker symbol(s) with exchange suffixes, countries, SEC filing status, CIK, PermID, and the unique company ID assigned by Captide. Results are sorted by name and paginated with `limit` (up to 1,000) and `offset`.

    `GET /api/v2/companies/search`\
    Type-ahead search by company name or ticker (for example `Apple`, `AAPL` or `STO.AX`).

    `GET /api/v2/companies/{id}`\
    Fetches a single company by its Captide company ID.
  </Accordion>
  <Accordion title="Documents" icon="file-contract">
    Endpoints to access company disclosures in either their original format or LLM-optimized Markdown.

    `GET /api/v1/documents/list`\
    Retrieves the documents that match your filters: document categories, SEC form types, company tickers or IDs, fiscal year and quarter, date range, or free text in the title and description. The response includes each document’s category, title, description, date, fiscal period, language, and the associated company. Results are sorted by `date`, newest first, by default; use `sortBy` (`date` or `name`) and `sortOrder` (`asc` or `desc`) to change it, and `limit` and `offset` to paginate.

    `GET /api/v2/documents/{id}`\
    Fetches a document by its ID. The response includes the document’s metadata, the associated company, and temporary links to the original file and its Markdown version.
  </Accordion>
  <Accordion title="Agentic RAG" icon="robot">
    Endpoints for leveraging Captide’s agentic AI workflows to programmatically extract insights and data from the document corpus.

    `POST /api/v2/rag/chunks`\
    Returns the document excerpts most relevant to a natural language query.

    `POST /api/v2/rag/company-retrieval`\
    Returns the companies a natural language query refers to (for example “Give me Estée Lauder and Louis Vuitton”).

    `POST /api/v2/rag/agent-response`\
    Returns a cited Markdown answer, sourced exclusively from corporate disclosures, to a natural language query.

    `POST /api/v2/rag/agent-response-stream`\
    Streams the same cited answer as Server-Sent Events, with progress updates while the agent works.
  </Accordion>
  <Accordion title="Webhooks" icon="bell">
    Endpoints to have new documents sent to your application as they are added. See the [Webhooks guide](/integration/webhooks).

    `POST /api/v2/webhooks`\
    Registers a URL to receive new documents, optionally only for some document categories.

    `GET /api/v2/webhooks`, `GET /api/v2/webhooks/{id}`, `PATCH /api/v2/webhooks/{id}`, `DELETE /api/v2/webhooks/{id}`\
    List, inspect, change, pause or delete your organization’s webhooks.
  </Accordion>
</AccordionGroup>

## API Conventions

- Authentication: API key in the **`X-API-Key`** header.
- JSON request and response fields use **camelCase** (e.g. `documentCategory`, `fiscalPeriod`, `companyId`).
- List filters take **comma-separated values** (e.g. `companyTickers=AAPL,MSFT`).
- URL paths use **kebab-case** (e.g. `/api/v2/rag/agent-response`).
- Dates use **ISO 8601** (`YYYY-MM-DD`).
- Errors return a JSON object with a `detail` field and a standard HTTP status code.

See [Versions and Conventions](/api-reference/versions) for which version of each endpoint to use, pagination, ticker formats and file links.
